# Проект

ядро для интернет-магазина

## Описание:

E-commerce  — электронная торговля, или электронная коммерция. 
На данном этапе работы мы не будем реализовывать систему платежей, однако подготовим всё для того, 
чтобы у нас появилось ядро для интернет-магазина. 
В дальнейшем для этого ядра возможно будет реализовать любой интерфейс — от сайта до телеграм-бота.

### В проекте реализованны следующие классы и функции:

Созданы классы Product и Category.
Добавлен класс CategoryIterator
Созданы два класса наследников класса Product: 
«Смартфон» (Smartphone) и «Трава газонная» (LawnGrass).
  
  Для класса Product определенны следующие свойства:
название (name),
описание (description),
цена (price),
количество в наличии (quantity).

  Для класса Category определенны следующие свойства:
название (name),
описание (description),
список товаров категории (products).

  Класс «Смартфон» (Smartphone) расширен атрибутами:
производительность (efficiency), 
модель (model), 
объем встроенной памяти (memory), 
цвет (color).

  Класс «Трава газонная» (LawnGrass) расширен атрибутами: 
страна-производитель (country), 
срок прорастания (germination_period), 
цвет (color).

  В классы Product и Category добавлены магические методы, геттеры и сеттеры
